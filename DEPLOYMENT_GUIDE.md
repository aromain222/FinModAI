## 🐳 Docker Deployment

### Dockerfile
```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    postgresql-client \
    && rm -rf /var/lib/apt/lists/*

# Copy requirements
COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application
COPY backend/ .

# Create necessary directories
RUN mkdir -p exports uploads

# Expose port
EXPOSE 8000

# Run application
CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]
```

### Docker Compose
```yaml
version: '3.8'

services:
  backend:
    build: .
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/finmodai
      - JWT_SECRET=${JWT_SECRET}
      - DATA_MODE=production
    depends_on:
      - db
    volumes:
      - ./exports:/app/exports
      - ./uploads:/app/uploads

  db:
    image: postgres:15
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=pass
      - POSTGRES_DB=finmodai
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

### Build and Run
```bash
# Build image
docker build -t finmodai-backend .

# Run with docker-compose
docker-compose up -d

# Check logs
docker-compose logs -f backend

# Stop
docker-compose down
```

## ☁️ Cloud Deployment

### Fly.io

#### 1. Install Fly CLI
```bash
curl -L https://fly.io/install.sh | sh
```

#### 2. Login
```bash
fly auth login
```

#### 3. Create App
```bash
fly apps create finmodai
```

#### 4. Set Secrets
```bash
fly secrets set JWT_SECRET="your-secret-here"
fly secrets set DATABASE_URL="postgresql://..."
fly secrets set ALPHAVANTAGE_API_KEY="..."
fly secrets set FINNHUB_API_KEY="..."
```

#### 5. Deploy
```bash
fly deploy
```

#### 6. Check Status
```bash
fly status
fly logs
```

### Render.com

#### 1. Create Web Service
- Connect GitHub repository
- Select `backend/` directory
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`

#### 2. Add PostgreSQL Database
- Create PostgreSQL database
- Add `DATABASE_URL` environment variable

#### 3. Set Environment Variables
```
JWT_SECRET=your-secret
DATA_MODE=production
DEBUG=False
```

#### 4. Deploy
- Auto-deploys on push to main
- Manual deploy available

### Railway

#### 1. Create Project
- Connect GitHub repository
- Select `backend/` directory

#### 2. Add PostgreSQL
- Add PostgreSQL plugin
- Auto-configured `DATABASE_URL`

#### 3. Set Variables
```
JWT_SECRET=your-secret
DATA_MODE=production
```

#### 4. Deploy
- Auto-deploys on push

## 🔒 Security

### JWT Secret
```bash
# Generate strong secret
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### Rate Limiting
```python
# Add to app.py
from slowapi import Limiter
from slowapi.util import get_remote_address

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter

@app.get("/api/v1/models/generate")
@limiter.limit("10/minute")
async def generate_model(...):
    ...
```

## 🧪 Testing in Production

### Smoke Test
```bash
# Health check
curl https://yourdomain.com/health

# Sign up
curl -X POST https://yourdomain.com/api/v1/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"Test123!","name":"Test User"}'

# Login
curl -X POST https://yourdomain.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"Test123!"}'

# Generate model
curl -X POST https://yourdomain.com/api/v1/models/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"model_type":"dcf","ticker":"AAPL"}'

# Download Excel
curl -X GET https://yourdomain.com/api/v1/models/{model_id}/excel \
  -H "Authorization: Bearer <token>" \
  --output test.xlsx
```

## 🐛 Troubleshooting

### Issue: Database connection failed
**Solution**: Check `DATABASE_URL` and database is running

### Issue: JWT token invalid
**Solution**: Check `JWT_SECRET` is set correctly

### Issue: API keys not working
**Solution**: Verify API keys are set and valid

### Issue: Export files not generating
**Solution**: Check file permissions and disk space

### Issue: High memory usage
**Solution**: Check for memory leaks, optimize queries
