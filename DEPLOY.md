## 🔧 Render Configuration

### render.yaml (Production Ready)
```yaml
services:
  - type: web
    name: finmodai
    env: python
    plan: free
    buildCommand: |
      echo "Starting build process..."
      python --version
      pip install --upgrade pip
      echo "Installing dependencies from requirements_production.txt..."
      pip install --no-cache-dir -r requirements_production.txt
      echo "Verifying critical dependencies..."
      python -c "import openpyxl; print(f'✓ openpyxl {openpyxl.__version__} installed')"
      python -c "import pandas; print(f'✓ pandas {pandas.__version__} installed')"
      python -c "import numpy; print(f'✓ numpy {numpy.__version__} installed')"
      python -c "import yfinance; print(f'✓ yfinance {yfinance.__version__} installed')"
      pip list | grep -E "(openpyxl|pandas|numpy|yfinance|flask|gunicorn)"
      echo "Build completed successfully"
    startCommand: gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120 --keep-alive 5 --max-requests 1000 --access-logfile - --error-logfile - --log-level info
    healthCheckPath: /healthz
    envVars:
      - key: FLASK_ENV
        value: production
      - key: FLASK_SECRET_KEY
        generateValue: true
```

## 🐛 Troubleshooting Render Crashes

### 1. ModuleNotFoundError: No module named 'openpyxl'
**Root Cause:** Missing dependencies in requirements.txt

**Solution:**
```bash
# Check requirements_production.txt includes:
openpyxl==3.1.2
pandas==2.0.3
numpy==1.24.3
yfinance==0.2.18

# Redeploy to rebuild image
git add requirements_production.txt
git commit -m "Add missing dependencies"
git push origin main
```

### 2. Exit Code 3 (Worker Failed to Boot)
**Root Cause:** Import errors at module level

**Solution:**
- ✅ Dependencies now validated at startup
- ✅ Clear error messages with exit code 1
- ✅ Build process verifies all imports

### 3. Health Check Failures
**Symptoms:** Service starts but health checks fail

**Check:**
- `/healthz` endpoint returns 200
- Service binds to `0.0.0.0:$PORT`
- No firewall issues

**Test:**
```bash
curl https://your-app.onrender.com/healthz
```

### 4. Port Binding Issues
**Symptoms:** "Address already in use" or connection refused

**Check:**
- Application reads `PORT` from environment
- Binds to `0.0.0.0:$PORT` (not `127.0.0.1`)
- No hardcoded port numbers
