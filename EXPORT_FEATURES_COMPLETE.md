## 📊 Usage Examples

### Generate and Download Excel

```bash
# 1. Generate DCF model
curl -X POST http://localhost:8000/api/v1/models/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "model_type": "dcf",
    "ticker": "AAPL"
  }'

# Response:
# {
#   "model_id": "3f9c8b2a-...",
#   "status": "succeeded",
#   ...
# }

# 2. Download Excel
curl -X GET http://localhost:8000/api/v1/models/3f9c8b2a-.../excel \
  -H "Authorization: Bearer <token>" \
  --output aapl_dcf.xlsx
```

### Generate and Download PDF

```bash
# 1. Generate DCF model (same as above)

# 2. Download PDF
curl -X GET http://localhost:8000/api/v1/models/3f9c8b2a-.../pdf \
  -H "Authorization: Bearer <token>" \
  --output aapl_dcf.pdf
```

## 🔧 Technical Details

### File Storage

**Location**: `backend/exports/`
**Naming**: `{model_type}_{ticker}_{timestamp}.{extension}`
**Database**: Files table tracks all exports

### Error Handling

**Excel Errors**:
- Missing data → Error message
- Invalid format → Fallback to text
- File write error → HTTP 500

**PDF Errors**:
- WeasyPrint unavailable → Fallback to ReportLab
- ReportLab error → HTTP 500
- Missing data → Error message

### Performance

**Excel Generation**: ~500ms for DCF model
**PDF Generation**: ~300ms (WeasyPrint) / ~200ms (ReportLab)
**File Size**: 
- Excel: ~50-100 KB
- PDF: ~100-200 KB
