# 🚀 MVP Implementation Plan - FinModAI

## 📋 Overview

This document outlines the complete implementation plan for the FinModAI MVP, following a structured 3-week timeline with clear acceptance criteria and technical specifications.

---

## 🎯 Tech Stack & Repo Layout

### Backend Stack
- **Framework**: FastAPI (Python 3.11)
- **HTTP Client**: httpx (async)
- **Data Processing**: pandas, pyarrow, numpy
- **Validation**: pydantic
- **Excel Export**: XlsxWriter
- **PDF Export**: WeasyPrint (primary) + ReportLab (fallback)
- **Auth**: JWT (PyJWT) + passlib (password hashing)
- **Database**: Postgres (prod) + SQLite (dev)
- **ORM**: SQLAlchemy + Alembic (migrations)

## 📅 Week 1: Core Functionality

### A) Model Generation Endpoints

**Endpoint**: `POST /api/v1/models/generate`

**Request Body**:
```json
{
  "model_type": "dcf|lbo|comps|merger",
  "ticker": "MSFT",
  "target": "ADBE",              // only for merger
  "custom_assumptions": {         // optional
    "wacc": 0.095,
    "terminal_growth": 0.025,
    "revenue_cagr_1_5": 0.07,
    "capex_pct_sales": 0.05,
    "delta_nwc_pct_sales": 0.01
  },
  "options": {
    "force_refresh": false,
    "currency": "USD"
  }
}
```

**Response (201)**:
```json
{
  "model_id": "3f9c8b2a-1d4e-4f5a-9b3c-2e7d8f1a6b4e",
  "status": "succeeded",
  "as_of_quotes": "2025-10-19T14:05:00Z",
  "as_of_fundamentals": "2025-09-30T00:00:00Z",
  "stale": false,
  "results": {
    "enterprise_value": 3521000.0,
    "equity_value": 3450000.0,
    "implied_price": 412.3,
    "upside_pct": 5.2
  },
  "provenance": {
    "revenue_fy2024": "edgar",
    "price": "yahoo",
    "ebitda": "edgar"
  },
  "warnings": []
}
```

**Error Responses**:
- `422`: Missing required fields
  ```json
  {
    "error": "validation_error",
    "code": "missing_fields",
    "fields": ["revenue", "ebitda"],
    "message": "Required fields missing for DCF model"
  }
  ```
- `503`: Data stale
  ```json
  {
    "error": "data_stale",
    "code": "quotes_too_old",
    "age_minutes": 45,
    "message": "Market quotes older than 30 minutes"
  }
  ```

**Implementation Flow**:
1. Validate request body (pydantic model)
2. Call `models_data/bundles.py` to fetch model inputs
3. Apply custom assumptions (if provided)
4. Run model via `models_data/generate.py`
5. Persist `ModelRun` record to database
6. Return results with provenance

**Acceptance Criteria**:
- ✅ POST `/models/generate` returns valid model for AAPL/MSFT
- ✅ No endpoint returns sample/dummy data
- ✅ Staleness check enforced (503 if > 30 min)
- ✅ Coverage check enforced (422 if < 3 years)

### B) Excel Export

**Endpoint**: `GET /api/v1/models/{model_id}/excel`

**Response**: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

**Excel Structure** (XlsxWriter):

#### Sheet 1: Summary
- Key outputs: EV, Equity Value, Implied Price, Upside %
- Assumptions table (condensed)
- Mini sensitivity grid (5×5 WACC × g)

#### Sheet 2: Projections
| Year | Revenue | EBIT | EBITDA | D&A | CapEx | ΔNWC | UFCF | PV Factor | PV UFCF |
|------|---------|------|--------|-----|-------|------|------|-----------|---------|
| 2025 | ...     | ...  | ...    | ... | ...   | ...  | ...  | ...       | ...     |

#### Sheet 3: Assumptions
- All custom inputs with units
- Auto-calc notes (e.g., "g < WACC ✓")
- Data sources

#### Sheet 4: Sensitivity
- 5×5 grid: WACC (rows) × Terminal Growth (cols)
- Bold min/max cells
- Color coding (green/red)

#### Sheet 5: Provenance
| Field | Provider | As Of |
|-------|----------|-------|
| Revenue | EDGAR | 2025-09-30 |
| Price | Yahoo | 2025-10-19 14:05 |

**Formatting Requirements**:
- Headers: Dark fill (#1e3a8a), white text, bold
- Numbers: Thousand separators, 2 decimals
- Percentages: 1 decimal place
- Borders: All cells
- Freeze panes: Row 1, Column labels
- Print area: Set for each sheet

**Acceptance Criteria**:
- ✅ Excel file opens in Excel/LibreOffice
- ✅ All sheets present with data
- ✅ Professional formatting applied
- ✅ Provenance sheet included

### C) PDF Export

**Endpoint**: `GET /api/v1/models/{model_id}/pdf`

**Response**: `application/pdf`

**PDF Structure** (WeasyPrint + ReportLab fallback):

1. **Header**
   - Company name, ticker
   - Model type, date/time
   - Generated by FinModAI

2. **Highlights**
   - Enterprise Value
   - Equity Value
   - Implied Price
   - Upside/Downside %

3. **Assumptions**
   - Key inputs in table format
   - Data sources

4. **Projections** (condensed table)
   - 5-year forecast

5. **Sensitivity Heatmap** (SVG)
   - Color-coded grid

6. **Provenance Summary**
   - Field → Provider mapping

7. **Footer**
   - `EXPORT_FOOTER_NOTE`

**Fallback Strategy**:
- Try WeasyPrint first
- If fails, use ReportLab basic summary (no charts)
- Log warning

**Acceptance Criteria**:
- ✅ PDF opens in Preview/Adobe Reader
- ✅ Footer note included
- ✅ Fallback works if WeasyPrint unavailable

### D) Basic Error Handling

**Unified Error Schema**:
```json
{
  "error": "validation_error|missing_fields|data_stale|provider_unavailable|reconciliation_failed|export_failed",
  "code": "specific_error_code",
  "message": "Human-readable message",
  "hints": ["Hint 1", "Hint 2"],
  "request_id": "uuid"
}
```

**Error Codes**:
- `validation_error`: Invalid input parameters
- `missing_fields`: Required fields missing
- `data_stale`: Data too old
- `provider_unavailable`: External API down
- `reconciliation_failed`: Data reconciliation error
- `export_failed`: Export generation failed

**Acceptance Criteria**:
- ✅ All errors return consistent JSON format
- ✅ Error codes are specific and actionable
- ✅ Hints provided for resolution

### B) Model History & Storage

**Database Schema**:

```sql
-- Users table
CREATE TABLE users (
    id UUID PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    email_hash VARCHAR(255) NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    name VARCHAR(255),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Model runs table
CREATE TABLE model_runs (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    model_type VARCHAR(50) NOT NULL,
    ticker VARCHAR(10) NOT NULL,
    target VARCHAR(10),              -- for merger models
    created_at TIMESTAMP DEFAULT NOW(),
    as_of_quotes TIMESTAMP,
    as_of_fundamentals TIMESTAMP,
    stale BOOLEAN DEFAULT FALSE,
    results_json JSONB,
    inputs_json JSONB,
    provenance_json JSONB,
    custom_assumptions JSONB
);

-- Files table
CREATE TABLE files (
    id UUID PRIMARY KEY,
    model_id UUID REFERENCES model_runs(id),
    kind VARCHAR(10) NOT NULL,        -- 'xlsx' or 'pdf'
    path VARCHAR(500) NOT NULL,
    size INTEGER,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_model_runs_user_id ON model_runs(user_id);
CREATE INDEX idx_model_runs_created_at ON model_runs(created_at DESC);
CREATE INDEX idx_files_model_id ON files(model_id);
```

**Endpoints**:
- `GET /api/v1/models?limit=20&offset=0` - List user's models
- `GET /api/v1/models/{model_id}` - Get specific model
- `DELETE /api/v1/models/{model_id}` - Soft delete model

**Acceptance Criteria**:
- ✅ Users see only their own models
- ✅ Models persist across sessions
- ✅ Pagination works
- ✅ Soft delete implemented

### C) Custom Assumptions

**Allowed Overrides**:

**DCF**:
```json
{
  "revenue_cagr_1_5": 0.07,           // 0-1
  "target_margin_ebit": 0.25,         // 0-1
  "target_margin_ebitda": 0.30,       // 0-1
  "wacc": 0.095,                      // 0-1
  "terminal_growth": 0.025,           // 0-1, must be < wacc
  "capex_pct_sales": 0.05,            // 0-1
  "delta_nwc_pct_sales": 0.01         // -1 to 1
}
```

**LBO**:
```json
{
  "entry_multiple": 10.0,             // > 0
  "exit_multiple": 12.0,              // > 0
  "leverage_ratio": 0.75,             // 0-1
  "interest_rate": 0.085,             // 0-1
  "amortization_pct": 0.01,           // 0-1
  "tax_rate": 0.25                    // 0-1
}
```

**Comps**:
```json
{
  "peer_tickers": ["AAPL", "MSFT", "GOOGL"]
}
```

**Merger**:
```json
{
  "premium_pct": 0.20,                // 0-1
  "synergy_pct": 0.15,                // 0-1
  "consideration_mix": {
    "cash": 0.5,
    "stock": 0.5
  }
}
```

**Validation Rules**:
- `terminal_growth < wacc`
- `revenue_cagr_1_5` between 0 and 1
- `leverage_ratio` between 0 and 1
- `premium_pct` between 0 and 1
- Reject unknown fields

**Acceptance Criteria**:
- ✅ Valid assumptions accepted
- ✅ Invalid assumptions return 422
- ✅ Unknown fields rejected
- ✅ Assumptions persist with model

## 📅 Week 3: Polish & Launch

### A) Validation & Guardrails

**Coverage Enforcement**:
- DCF requires ≥ 3 years of revenue + EBIT/EBITDA
- LBO requires ≥ 3 years of EBITDA + FCF
- Comps requires ≥ 3 peers with data
- Merger requires both companies' data

**Sanity Checks**:
- `terminal_growth < wacc` (warning if violated)
- Denominators > 0 for ratios
- `market_cap ≈ price * shares_out` within 15% (warning)
- Terminal value < 80% of EV (warning)

**Warnings Array**:
```json
{
  "warnings": [
    "Terminal value is 82% of EV (typically < 80%)",
    "Market cap differs from price × shares by 18%"
  ]
}
```

**Acceptance Criteria**:
- ✅ Coverage checks enforced
- ✅ Sanity checks run
- ✅ Warnings included in response

## 🚦 Hard Guards (Production Only)

### Middleware Rules

1. **No Dummy Data**:
   - If payload contains `"placeholder": true`, `"demo"`, `"mock"` → 500 blocked_by_policy
   - If missing `as_of_quotes` or `as_of_fundamentals` → 500 blocked_by_policy

2. **Staleness Check**:
   - If quotes `as_of` older than `DATA_STALENESS_MAX_MIN` → 503 data_stale

3. **Coverage Check**:
   - If coverage fails → 422 missing_fields with precise list

4. **Auth Required**:
   - All `/api/v1/models/*` routes require `Authorization: Bearer <token>`
